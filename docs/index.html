Every branch gets its own folder. wtm keeps them all in view.

A native Git worktree manager for macOS and Linux. See every repository and every worktree with its status, then create, switch, and prune without leaving the window. A CLI and a full-screen TUI ship alongside it for the terminal.

What the app does

Built with GPUI, the framework behind Zed. Every git operation is shared with the CLI and TUI, so the three never disagree about a worktree.

Repositories
Every repo you have opened sits in the sidebar, sorted by name and stable, so nothing jumps when you click it.
Live status
A filesystem watcher keeps the list current. Commit in a terminal or switch a branch in your editor and the row updates.
Dirty counts
Each row shows how many files are dirty, plus ahead, behind, merged, gone, missing, and locked.
Create and switch
New worktree from any base ref, with your setup commands run and your env files copied. Open one in your editor or terminal.
Prune with a preview
Pick merged and upstream-gone worktrees, see exactly what will go, and remove a hundred at a time with progress.
Keyboard first
⌘K opens a palette over worktrees and actions. Focus is always visible and dialogs keep Tab inside them.
From the shell
Running wtm with no arguments on a terminal opens the app. Piped or scripted calls still print help and exit 0.

The daily loop

Three steps, and the same three commands in the app, the TUI, and the CLI.

  1. Give the branch a folder

    Start from any ref. Setup runs and env files are copied before you open it.

    wtm add feature/login
wtm add --from origin/main hotfix

  2. Work without collisions

    Open a worktree in your editor, run a command inside it, or move your shell there.

    wtm open feature/login
wtm switch feature/login

  3. Prune what is finished

    Preview merged and upstream-gone worktrees, then remove them. Dirty ones and protected branches stay.

    wtm prune --merged --gone --dry-run
wtm prune --merged --gone

The same tool from the terminal

Use the CLI from scripts and agents. Launch the TUI when you want to browse and act with the keyboard.

Browse in the TUI recording selected

Browse in the TUI
wtm list
Every registered worktree. Add --json for stable output or --fast to skip status.
wtm add
Create a worktree and branch, run setup, copy env files.
wtm switch
Move your shell into a worktree through the wtm init wrapper.
wtm prune
Remove merged and upstream-gone worktrees after a dry run.
wtm open
Open a worktree in your editor, or run a command inside it.

Project defaults live in .worktree.toml; editor and setup commands live in the git-ignored .worktree.local.toml, so a shared config can never run code. Dirty worktrees refuse removal without --force, and main and protected branches are never selected for cleanup.
