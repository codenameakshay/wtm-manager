## Findings considered and rejected (not 0.10.0)

- **Windows GUI/CLI.** `src/lib.rs` is a hard `compile_error` for anything but macOS/Linux. Linux GUI is still CI-only. Windows in 0.10 is a platform rewrite.
- **MCP server.** No MCP surface exists. Wrapping today's holes (no unique add, no mutation JSON, no leftover prune) would freeze a weak contract. Candidate for 0.11 after the CLI contract lands.
- **wtm-owned worktree database / plugin system.** 0.1.0 already decided git's registry is source of truth. Provenance belongs in an overlay later, not a parallel manager.
- **Apple notarization.** Real Gatekeeper friction, but it is an Apple Developer ID / CI secrets problem, not a feature. Track as 0.11 ops.
- **Path-prefix guessing** (`t3code-*`, `.claude/worktrees/`, `cursor/`) as creator labels. Layouts change; false labels are worse than none.
- **Changing `wtm add <branch>` to auto-suffix on `BranchInUse`.** Silent extra branches would surprise the GUI/TUI, which share `create_core`. Unique create must be an explicit flag.
- **`ink`/`hairline` gpui truncation workarounds.** DESIGN.md documents these as required around gpui 0.2.2 bugs. Do not "clean them up."
